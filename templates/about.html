ECPE AI Lab

An AI-powered web application for Emotion-Cause Pair Extraction from multi-turn conversations. The system automatically detects the emotion expressed in each utterance and traces back the utterance that caused it.

🧠

💡 What It Does

Given a conversation between two or more speakers, ECPE AI Lab performs two tasks simultaneously:

🎭
Emotion Detection

Classifies each utterance into one of seven emotion categories: Joy, Sadness, Anger, Fear, Surprise, Disgust, or Neutral — with a confidence score.

🔗
Cause Extraction

Identifies the prior utterance that triggered each emotional reaction, extracting the specific cause span and explaining the reasoning.

🤖 ML Models Used

Four classifiers run in parallel on every prediction

📐

Logistic Regression

Linear probabilistic classifier using softmax over TF-IDF + lexicon features. Fast and interpretable.

LinearProbabilistic
✂️

Support Vector Machine

Maximum-margin hyperplane classifier in high-dimensional TF-IDF feature space. Strong on text tasks.

Max-MarginLinearSVC
🎲

Naive Bayes

Multinomial Naive Bayes using word frequency distributions per emotion class. Extremely fast.

ProbabilisticFast
🌲

Random Forest

Ensemble of 200 decision trees capturing non-linear interactions between TF-IDF and lexicon features.

Ensemble200 Trees
